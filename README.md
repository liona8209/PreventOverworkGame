# 🛡️ 過勞防護不心苦－預防過勞大挑戰

一款單頁式衛教互動小遊戲，玩家透過觀看 **8 組情境圖卡**與說明文字，逐題判斷該行為或環境是「減少過勞風險」還是「增加過勞風險」，加深對過勞成因與預防辦法的認知。

🎮 **線上試玩**：https://liona8209.github.io/PreventOverworkGame/

---

## 📖 遊戲介紹

遊戲共分三個畫面：

1. **開始畫面**：顯示遊戲規則說明，點擊「🚀 開始挑戰」進入第一題。
2. **作答畫面**：單次畫面只呈現 1 道題目——
   - 上方顯示「進度」（第 X 題 / 共 8 題）與「得分」兩個資訊卡
   - 中間置中顯示情境插圖、情境標題與說明文字
   - 下方提供兩個大按鈕：🟢【減少過勞風險】／🔴【增加過勞風險】
   - 點擊其中一個按鈕後立即鎖定選項，正確答案會亮起綠色光暈、答錯的選項亮起紅色，並在上方顯示「✅ 答對了！」或「❌ 答錯囉！」，同時出現「➡️ 下一題」按鈕
3. **結算畫面**：完成 8 題後顯示總得分（例如「你答對了 8 / 8 題！」），並提供「🔄 重新開始」按鈕再玩一次。

畫面最上方也有一顆常駐的「🔄 重新開始」按鈕，隨時可以回到開始畫面重新挑戰。

## 🗂️ 8 道題目內容

### 🛡️ 減少過勞風險（4 題）
| 情境 | 說明 |
|---|---|
| 健康管理 | 定期健康檢查與追蹤 |
| 身體活動 | 規律適度運動 |
| 充足休息 | 適當休息 |
| 壓力調適 | 適度調節工作壓力 |

### ⚠️ 增加過勞風險（4 題）
| 情境 | 說明 |
|---|---|
| 極端壓力工作 | 極度緊張、精神負荷高的工作 |
| 特殊工時與班別 | 不規律的工作、輪班或夜班等特殊作業環境 |
| 不良作業環境 | 異常高、低溫環境或充斥噪音等特殊作業環境 |
| 過重負荷 | 長期工作過重或短期工作超過負荷 |

## 🕹️ 操作方式

- 點擊「🚀 開始挑戰」開始作答
- 每題點擊「🟢 減少過勞風險」或「🔴 增加過勞風險」其中一個作答，答案會立即鎖定並顯示對錯
- 點擊「➡️ 下一題」繼續下一題，直到完成全部 8 題看到結算畫面
- 畫面上方「🔄 重新開始」／結算畫面的「🔄 重新開始」都可以讓遊戲重頭再來一次

## 🛠️ 技術規格

- **前端技術**：純 HTML5 + CSS3（Flexbox 響應式排版、玻璃感 backdrop-filter 效果）+ 原生 JavaScript
- **相容性**：支援主流桌面瀏覽器（Chrome, Edge, Safari, Firefox）以及手機／平板觸控，並支援畫面自由縮放
- **部署方式**：單一 `index.html` 檔案 + `Image/` 圖片資料夾，無需安裝任何套件、資料庫或伺服器環境，雙擊即可離線執行，亦可直接部署於 GitHub Pages 線上瀏覽

## 💻 本機執行方式

直接下載整個專案後，雙擊 `index.html` 即可在瀏覽器開啟遊玩；或使用任一本機伺服器（例如 VS Code 的 Live Server、`npx serve`）開啟，體驗與線上版本相同。

```bash
git clone https://github.com/liona8209/PreventOverworkGame.git
cd PreventOverworkGame
npx serve .
```

## 🌐 部署到 GitHub Pages

1. 到 Repo 的 **Settings → Pages**
2. **Build and deployment → Source** 選擇 `Deploy from a branch`
3. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**
4. 幾分鐘後即可透過以下網址遊玩：

   ```
   https://liona8209.github.io/PreventOverworkGame/
   ```

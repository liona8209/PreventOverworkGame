# 🛡️ 辛苦了，別心苦－過勞預防分類挑戰

一款單頁式衛教互動小遊戲，透過**拖拉分類（Drag & Drop）**的方式，讓玩家練習分辨「降低過勞風險」與「提高過勞風險」的各項因子，加深對過勞成因與預防辦法的認知。

🎮 **線上試玩**：https://liona8209.github.io/PreventOverworkGame/
（需先在 Repo 的 Settings → Pages 啟用後才能使用此網址）

---

## 📖 遊戲介紹

畫面下方會隨機打散 **8 張圖卡**，玩家需將每張卡片拖曳到左側或右側正確的欄位中：

| 欄位 | 主題色 | 說明 |
|---|---|---|
| 🛡️ 降低過勞風險區 | 綠色系 | 健康、保護與維護的正向行為 |
| ⚠️ 提高過勞風險區 | 紅橙色系 | 負荷、危險與警示的高風險因子 |

全部 8 張卡片放置完成後，點擊 **「✅ 檢查答案」**：

- ✅ 分類正確的卡片 → 邊框與背景轉為**綠色**
- ❌ 分類錯誤的卡片 → 邊框與背景轉為**紅色**（並提示重新調整）

系統會依情況顯示三種提示訊息：

- ⚠️ **尚未完成**：「還有圖卡尚未分類完成，請全部拖拉至欄位後再檢查！」
- 🎉 **全部正確**：「太棒了！全部分類正確！你已經完全掌握了預防過勞的核心觀念！」
- ❌ **部分錯誤**：「有部分圖卡分類錯誤（紅框標示），請調整後再次檢查！」

點擊 **「🔄 重新開始」** 可重新洗牌、清空欄位，再玩一次。

## 🗂️ 圖卡分類內容

### 🛡️ 降低過勞風險組
| 圖卡 | 說明 |
|---|---|
| 健康管理 | 定期健康檢查與追蹤 |
| 身體活動 | 規律適度運動 |
| 充足休息 | 適當休息 |
| 壓力調適 | 適度調節工作壓力 |

### ⚠️ 提高過勞風險組
| 圖卡 | 說明 |
|---|---|
| 極端壓力工作 | 極度緊張、精神負荷高的工作 |
| 特殊工時與班別 | 不規律的工作、輪班或夜班等特殊作業環境 |
| 不良作業環境 | 異常高、低溫環境或充斥噪音等特殊作業環境 |
| 過重負荷 | 長期工作過重或短期工作超過負荷 |

## 🕹️ 操作方式

- **滑鼠**：按住卡片拖曳至任一欄位放開即可
- **觸控（手機／平板）**：手指按住卡片拖曳至欄位放開即可
- 在點擊「檢查答案」之前，卡片可以在「圖卡區」與左右兩個欄位之間**自由來回移動**
- 未完成分類、或分類錯誤時都可以繼續調整，沒有次數限制

---

## 🛠️ 技術規格

- **前端技術**：純 HTML5 + CSS3（Flexbox / Grid 響應式排版）+ 原生 JavaScript
- **拖放實作**：使用 [Pointer Events API](https://developer.mozilla.org/docs/Web/API/Pointer_events) 自製拖放邏輯（同時支援桌面滑鼠、觸控螢幕、觸控筆），比原生 HTML5 Drag and Drop API 對行動裝置更友善
- **相容性**：支援主流桌面瀏覽器（Chrome, Edge, Safari, Firefox）以及手機／平板觸控
- **部署方式**：單一 `index.html` 檔案 + `Image/` 圖片資料夾，無需安裝任何套件、資料庫或伺服器環境，雙擊即可離線執行，亦可直接部署於 GitHub Pages 線上瀏覽

## 💻 本機執行方式

直接下載整個專案後，雙擊 `index.html` 即可在瀏覽器開啟遊玩；或使用任一本機伺服器（例如 VS Code 的 Live Server、`npx serve`）開啟，體驗與線上版本相同。

```bash
git clone https://github.com/liona8209/PreventOverworkGame.git
cd PreventOverworkGame
npx serve .
```

## 🌐 部署到 GitHub Pages

1. 到 Repo 的 **Settings → Pages**
2. **Build and deployment → Source** 選擇 `Deploy from a branch`
3. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**
4. 幾分鐘後即可透過以下網址遊玩：

   ```
   https://liona8209.github.io/PreventOverworkGame/
   ```
